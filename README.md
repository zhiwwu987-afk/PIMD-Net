# PIMD-Net
Official implementation of "Physics-Informed Demodulation Network with Adaptive Soft Thresholding for Gear Eccentricity Diagnosis in Strong Noise"

# Introduction
This repository provides the official implementation of PIMD-Net (Physics-Informed Cross-Domain Diagnosis Network with Asymmetrical Attention), designed to tackle gear eccentricity fault diagnosis under complex industrial conditions.

In real-world scenarios, varying transmission chain lengths, fluctuating speeds, and intense background noise severely limit traditional diagnostic models. To overcome this, PIMD-Net integrates physical priors with a data-driven time-frequency dual-stream architecture, ensuring both high diagnostic precision and exceptional robustness.
